# 파이트 메이커 (making-fight)

나만의 격투가를 만들어 CPU나 친구와 싸우는 브라우저 격투 게임입니다.
`index.html` 파일 하나로 동작하고, 설치할 것이 없습니다. 아이폰·아이패드 사파리, 안드로이드, PC 브라우저에서 모두 됩니다.

## 할 수 있는 것

- **파이터 만들기**: 이름, 격투 스타일 5종(복서 · 태권도 · 레슬러 · 쿵푸 · 닌자), 능력치 12포인트 분배(힘 · 스피드 · 맷집 · 기술), 체형 · 머리 모양 · 옷차림(로봇 장갑 포함) · 색상을 정합니다. "랜덤 생성"으로 한 번에 만들 수도 있어요. 만든 파이터는 브라우저에 저장됩니다.
- **나만의 무술** ([Fighting Robots · ROBOT88](https://store.steampowered.com/app/1732650/Fighting_Robots/)에서 영감):
  1. **무술**: 무술 이름, 가르침 한 줄, 손가락으로 그리는 **낙관(도장)**. 낙관은 대전 화면과 비급서에 찍혀요.
  2. **자세**: 관절을 끌어 기본 자세와 막기 자세를 만들어요.
  3. **초식**: 화면을 누른 채 손가락을 움직이면 손이나 발이 그대로 따라 움직이고, 그 동작이 초식이 돼요(최대 1.2초). 펀치·킥·앞+펀치·앞+킥·뒤+펀치·뒤+킥 6칸이 있어요.
     - 빠르게 휘두른 구간만 맞고, 오래 빠르게 휘두를수록 세져요.
     - 위로 올려치면 상대를 띄우고, 아래로 내려찍으면 넘어뜨리고, 옆으로 치면 밀어내요.
     - 맞힌 직후 어떤 초식으로 이어질지(연계)를 직접 정해요.
  4. **비급**: 내 초식을 분석해 "상단 · 원거리 · 속공 연환형" 같은 무술 성향과 그래프를 보여 줘요.
- **CPU 대전**: 난이도(쉬움 · 보통 · 어려움)와 스테이지(도장 · 노을 옥상 · 챔피언 링)를 골라 3판 2선승으로 싸웁니다.
- **온라인 대전**: 한 명이 방을 만들면 4자리 코드가 나오고, 친구가 그 코드를 입력하면 바로 붙습니다.

## 조작법

| 동작 | 터치 | 키보드 |
|---|---|---|
| 이동 | ◀ ▶ | ← → 또는 A D |
| 점프 | ▲ | ↑, W, Space |
| 막기 | 막기 | ↓ 또는 S |
| 펀치 | 펀치 (앞/뒤를 누른 채면 다른 초식) | J (또는 Z) |
| 킥 | 킥 (앞/뒤를 누른 채면 다른 초식) | K (또는 X) |
| 필살기 | 필살 | L (또는 C) |
| 일시정지 | 화면 위 ❚❚ | Esc |

- "앞"은 상대가 있는 쪽이에요. 초식이 맞은 직후 다음 초식 명령을 누르면 내가 정한 연계대로 이어집니다(최대 4연계).
- 필살기 게이지가 50 이상이면 필살기를 쓸 수 있고(최대 2칸), 펀치·킥이 맞은 직후에 누르면 바로 이어집니다.
- 막기는 대미지를 크게 줄이지만 레슬러의 잡기(바디 슬램)는 막을 수 없습니다.
- 60초 안에 쓰러뜨리지 못하면 남은 체력 비율로 판정합니다.

## 온라인 대전은 어떻게 연결되나요?

게임이 열린 곳에 따라 연결 방식이 자동으로 정해집니다.

1. **Claude 아티팩트 링크로 열었을 때**: Claude의 실시간 방 기능으로 연결합니다. 친구도 같은 아티팩트를 열 수 있어야 하므로, 아티팩트의 공유 메뉴에서 친구를 초대해 주세요.
2. **그 밖의 주소로 열었을 때**(GitHub Pages, 학교 서버, 내 PC 등): [PeerJS](https://peerjs.com/)를 이용한 WebRTC P2P 연결을 씁니다. 방 코드를 주고받을 때만 PeerJS 공개 서버를 거치고, 대전 데이터는 두 기기가 직접 주고받습니다. 같은 와이파이에 있으면 가장 빠르고, 다른 네트워크끼리도 대부분 연결됩니다.

호스트(방을 만든 사람)의 기기가 경기를 계산하고, 참가자는 입력만 보내고 화면을 받아 그립니다.

### 내 주소로 띄우기

`index.html`만 정적 웹 서버에 올리면 됩니다. 예를 들어 같은 와이파이의 PC에서:

```bash
python3 -m http.server 8000
```

을 실행하고 휴대폰 사파리에서 `http://<PC의 IP 주소>:8000` 으로 접속하면 됩니다. (온라인 대전의 방 코드 교환에는 인터넷 연결이 필요합니다.)

### 테스트용 로컬 모드

주소 끝에 `#local`을 붙여 같은 브라우저의 탭 두 개로 열면, 인터넷 없이 탭끼리 온라인 대전을 시험해 볼 수 있습니다.

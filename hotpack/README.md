# 주머니 핫팩 (구상 + 프로토타입)

`hotpack/index.html` 파일 하나로 동작하는 핫팩 앱입니다. 파이트 메이커처럼 설치 없이 아이폰·안드로이드·PC 브라우저에서 열립니다.

## 기능 3가지

### 1. 🧤 가상 핫팩 — "흔들고 문질러서 데우기"
- 화면 속 핫팩을 손가락으로 문지르거나, **흔들기**를 켜고 휴대폰을 흔들면 온도가 올라갑니다(18°C → 최대 62°C).
- 뜨거워질수록 색이 파랑 → 주황 → 빨강으로 바뀌고, 38°C를 넘으면 김이 피어오릅니다.
- 가만히 두면 천천히 식습니다. 오늘 데운 횟수와 최고 온도를 기록합니다.
- 아이폰은 흔들기를 처음 켤 때 "동작 및 방향" 권한을 묻습니다.

### 2. 🔥 진짜로 데우기 — 발열 모드
- Web Worker로 CPU 코어를 일부러 바쁘게 돌려 휴대폰 자체를 살짝 따뜻하게 만듭니다.
- 세기(약하게 1코어 / 보통 절반 / 세게 전부)와 시간(3·5·10분)을 고릅니다.
- **온도 대신 "칩 속도"를 보여 줍니다.** 웹에서는 기기 온도를 읽을 수 없지만, 기기가 뜨거워지면 스스로 속도를 낮추기(스로틀링) 때문에 처음 대비 속도가 떨어지는 것을 "충분히 따뜻해졌다"는 신호로 씁니다.
- 안전장치: 정해진 시간이 지나면 자동 종료, 다른 앱/화면으로 넘어가면 즉시 종료, 배터리 정보를 읽을 수 있는 기기에선 충전 중이거나 20% 미만이면 시작하지 않음, 화면 꺼짐 방지(Wake Lock).

### 3. ⏱️ 핫팩 타이머 — 진짜 핫팩 관리
- 진짜 핫팩을 뜯을 때 종류(주머니 12h · 붙이는 12h · 대용량 16h · 발 6h · 미니 6h)를 골라 등록합니다. 시간은 직접 바꿀 수 있고, "1시간 전에 뜯었어요"처럼 소급 등록도 됩니다.
- 남은 시간, 끝나는 시각, 단계(데워지는 중 → 따뜻함 최고 → 식어가는 중 → 다 썼어요)를 보여 줍니다.
- 저온 화상 주의 안내를 함께 둡니다.

데이터(타이머, 오늘 기록)는 브라우저 localStorage에만 저장됩니다.
